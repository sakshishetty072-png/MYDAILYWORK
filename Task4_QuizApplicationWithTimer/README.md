# Quiz Application with Timer (Java)

## Description
A console-based Quiz Application developed using Java. 
Users answer multiple-choice questions within a fixed 10-second time limit. 
The application calculates the final score and displays a detailed result summary.

## Features
- 10-second timer for each question
- Multiple-choice questions
- Automatic score calculation
- Final score with percentage
- Detailed summary (Correct / Wrong / Time Up)
- Performance evaluation message

## Technologies Used
- Java
- OOP Concepts
- Collections (ArrayList)
- Multithreading (ExecutorService, Future)

## How to Run (Command Line)

1. Open terminal / command prompt
2. Navigate to project folder
3. Compile the program:

   javac QuizApplication.java

4. Run the program:

   java QuizApplication

5. Answer each question within 10 seconds
6. View your final score and summary

## Learning Outcomes
- Understanding of OOP concepts
- Implementation of multithreading
- Handling user input with time constraints
- Score tracking and result evaluation
