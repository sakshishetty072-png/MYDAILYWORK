# Student Course Registration System (Java)

## 📌 Description

A console-based **Student Course Registration System** developed using Java.  
This application allows students to:

- View available courses
- Register for courses
- Drop registered courses
- View registered courses

The system manages course capacity and prevents duplicate registrations.

---

## 🚀 Features

- Course Database (Code, Title, Description, Capacity, Schedule)
- Student Database (Student ID, Name)
- Display available courses with remaining slots
- Course Registration
- Course Removal (Drop Course)
- Prevent duplicate registration
- Capacity management for each course
- Menu-driven console interface

---

## 🛠 Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Collections (ArrayList)
- Iterator
- Scanner (User Input Handling)

---

## 🧩 System Modules

### 1️⃣ Course Class
- Stores course details
- Tracks enrolled students
- Checks course availability
- Handles enroll and drop functionality

### 2️⃣ Student Class
- Stores student information
- Maintains registered courses list
- Prevents duplicate course registration

### 3️⃣ CourseRegistrationSystem (Main Class)
- Displays menu options
- Handles course registration logic
- Handles course drop logic
- Displays available and registered courses

---

## ▶ How to Run (Command Line)

1. Open Terminal / Command Prompt
2. Navigate to the project folder
3. Compile the program:

```bash
javac CourseRegistrationSystem.java
```

4. Run the program:

```bash
java CourseRegistrationSystem
```

5. Enter Student ID and Name
6. Select options from the menu
